# Pay UX/UI audit — 18 September 2026

Scope: development only (`https://dev-pay.epsx.io`), plus the repository's loopback browser fixture for authenticated merchant data and checkout states. No production routes, database migrations, real wallet signatures or payments.

## Findings and fixes

- Dev Pay and its required dev services were stopped, causing the initial Cloudflare 502. Started the existing dev LaunchAgents for Pay, Anvil, backend, wallet and Pay service.
- The home Dashboard action was rendered below the shared navigation. Moved it into the shared header and grouped merchant session actions with the environment controls.
- Overview creation links and payment-detail links dropped the selected environment. Preserve the environment in their destinations, including navigation between the two documentation pages.
- Signed-out escrow unnecessarily depended on native payment configuration and returned 502. Render its sign-in view without calling that upstream. Added an offline-upstream regression test.
- Documentation depended on missing prose styling and displayed internal development instructions with unserved relative links. Added a user-facing merchant guide and explicit typography, table/code scrolling, spacing and theme styles.
- A checkout without its capability displayed an indefinite loading spinner. Show an incomplete-link explanation and a recovery link; distinguish loading failures from active loading. Preserve pending-transaction behavior.
- Expired merchant checkout pointed to EPSX plans. Return merchant customers to their storefront; retain the plan destination for EPSX purchases.
- Legacy `/checkout/:id` lost the shared navigation. Only the dedicated `/checkout/cs_*` screen now suppresses that header.
- The empty overview callout occupied one statistics-grid column. Let its introduction and action panel span the grid.
- Long webhook URLs and variable action counts produced awkward grid rows. Use wrapping rows with constrained text and touch-sized controls.
- Center the landing-page sample QR. Improve payment-detail label/value spacing, helper-text spacing, error-checkout width and narrow checkout headers.
